BBTS LIVE HUB - flyer folder

Recommended file naming:
YYYY-MM-DD-short-name.jpg

Example:
2026-11-28-mixed-hell.jpg

Then add this field to the matching event in events.json:
"flyer": "assets/flyers/2026-11-28-mixed-hell.jpg"

The flyer is intentionally shown only inside the event detail modal,
so ALL SCHEDULE remains compact and easy to scan.
